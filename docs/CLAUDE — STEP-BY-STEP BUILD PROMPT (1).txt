==================================================
SECURITY REQUIREMENTS
==================================================

Throughout the project follow these rules:

1. Hash passwords.
2. Never return password hashes to the frontend.
3. Never store secrets in React.
4. Use environment variables.
5. Validate API input.
6. Check authenticated user ownership.
7. Do not allow user A to access user B's transactions.
8. Use parameterized SQL queries.
9. Do not expose arbitrary SQL execution.
10. Configure CORS intentionally.
11. Do not enable debug mode in production.
12. Use HTTPS in production.
13. Do not commit secrets to Git.
