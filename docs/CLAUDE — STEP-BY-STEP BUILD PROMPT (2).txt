============================================================
WHY SQLITE LOCALLY
============================================================

SQLite is excellent for learning.

It is:

- Simple
- Lightweight
- File based
- Easy to configure
- No database server required


Use:

SQLite

during development.


For production:

Use PostgreSQL.

Do not rely on a local SQLite file for production persistence
on a typical cloud deployment unless persistent storage has
been deliberately configured and the limitations are understood.
